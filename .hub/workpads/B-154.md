# Workpad: B-154

## Scope and state

B-154 is an open format-expressivity decision. This branch contributes a
non-normative proposal for Brett in `docs/i-adopt-relation-options.md` and an
entrypoint link. It does not adopt either option, change a released SDP
profile, alter the schema, or close the queue item's retirement condition.
B-114 is still `needs_brett` and must establish spec ownership of the
`metadata/semantic/` decomposition layout before any normative addition here.

  decomposition shape. Both accept only `value_of_dimension`, connecting

  the inspected metasalmonpy checkout was

## Candidate design

Option A proposes a separate optional relation table keyed to existing
decomposition rows; Option B explicitly refuses that expressivity and tells
consumers to obtain an independently authored I-ADOPT description or report
missing links. Option A is recommended as a design target because it can carry
the ontology's existing predicates without changing frozen decomposition rows.
No term, role, schema, or implementation was changed by this branch.
