## Guard retirement

The live test skips only when the independent known-good vocabulary probe cannot
be reached by the runner, including a confirmed outage during a target fetch.
HTTP errors, invalid Turtle, missing fragments and wrong types do not become
success. This offline skip retires if the test moves to a network-required job
where transport failure must fail the build. The offline row and RDF checks run
regardless of network reach.
