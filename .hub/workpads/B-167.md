# B-167 — Align procedure prose with the reachability rule

## Change

The human-readable specification, authored template README, mixed-grain
example, and `tables.schema.json` method-field description now describe the
ruled vocabulary-graph check: a shared-vocabulary method IRI reaches a
resource typed `sosa:Procedure` through zero or more `skos:broader` steps.
Direct typing is the zero-step case. The specification gives its own rationale
and distinguishes graph reachability from per-IRI HTTP dereference and from an
OWL typing entailment. It also says that a quality rating is not a procedure
code, matching the unchanged rules. The example explicitly calls its
`example.org` IRIs placeholders.

`scripts/generate_artifacts.py --write` propagated the two authored template
and schema changes to `templates/salmon-data-package-template/README.md`,
`docs/field-reference.md`, and the deterministic template ZIP. The ZIP is a
third generated container of the README, not another authored site; the queue
item counts the two generated prose files. `CHANGELOG.md` records the prose
correction under Unreleased. No machine-readable rule ID or condition changed.

## Independent basis for the wording

- [SOSA's `Procedure` definition](https://www.w3.org/TR/vocab-ssn/#SOSAProcedure)
  describes a reusable plan or method as an OWL class; `usedProcedure` points
  at one. [SKOS S19–S22](https://www.w3.org/TR/skos-reference/#semantic-relations)
  make semantic relations concept-to-concept. A `skos:broader` edge to the
  class would treat that class as a concept; it does not type the narrower
  method as a Procedure.
- The published [DFO ontology at tag 0.0.9](https://github.com/dfo-pacific-science/dfo-salmon-ontology/blob/0.0.9/ontology/dfo-salmon.ttl#L1024-L1038)
  types `smn:EnumerationMethod` as `sosa:Procedure` and places
  `gcdfo:FixedSiteCensusManual` below it. The [Salmon Domain Ontology method
  shape at current main](https://github.com/salmon-data-mobilization/salmon-domain-ontology/blob/0e420373e2fb76b752e03bc10060884d711773be/ontology/shapes/method-shapes.ttl#L20-L24)
  checks a zero-or-more `skos:broader` path. Both were read at the linked
  revisions, separately from `schema/sdp.rules.yaml`.
- Brett's 2026-09-14 Q47 ruling is in metasalmon
  `knowledge/questions.md`; the accepted SDP rationale is in
  `docs/adr/0002-sosa-procedure-reachability.md`. These govern the intended
  policy, while the W3C and ontology sources above independently explain why
  the wording fits the model.

## Review boundary

This edits human-readable validity prose and is therefore a semantic choice
for Brett to review in a draft PR. There is a pre-existing tension outside
B-167's scope: `protocol_iri` may name a published DOI or URL in the
specification, while the unchanged rule says every protocol IRI must be
declared by a shared vocabulary and reach `sosa:Procedure`. This change
neither resolves nor conceals that tension; it needs its own decision before
the rule becomes executable.
